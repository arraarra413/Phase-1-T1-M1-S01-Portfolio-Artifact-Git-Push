# Week 04 — Virtualization & Containers

## What I Learned
This week explored microservices architecture, infrastructure containerization, and configuration isolation using Docker.

## Artifacts
- **docker-compose.yml**: A deployment configuration orchestrated to stand up an isolated web service environment.

## Challenges
Overlapping host port allocations caused runtime failures; resolved by re-mapping internal service ports.

## Reflection
Container orchestration shifts our architectural mindset away from bulky virtual installations toward rapid, immutable layers.
